Portfolio consulenziale

Benvenuto in WayFold Compliance

Per iniziare un workflow consulenziale operativo, completa questi passi. Le metriche del Portfolio appariranno quando esisterà almeno un programma.

  1. 1. Crea il primo cliente
  2. 2. Crea un programma di compliance
  3. 3. Seleziona i framework (con versione pinned)
  4. 4. Genera la checklist unificata

Readiness indica avanzamento implementativo, non una dichiarazione automatica di conformità.

La creazione guidata cliente/programma sarà esposta dopo il bridge GRC autenticato. Nel frattempo usa seed/staging o l’import programma.
